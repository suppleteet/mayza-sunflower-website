# Sunflower Garden Nursery School Website

Static multi-page website for Sunflower Garden Nursery School.

## Files

- `index.html` is the home page.
- `about.html`, `daily-life.html`, `photos.html`, and `contact.html` are separate page loads.
- `daily-life.html` also carries the nutrition content (`#nutrition`).
- `contact.html` includes program details, attendance options, and enrollment policies.
- `styles.css` contains the visual design and responsive layout.
- `script.js` handles the mobile menu and footer year.
- `assets/sunflower-logo-refined.png` is the transparent logo used for the favicon, header, and home hero.
- `assets/mayza.png` is the founder portrait on the about page.

## Preview

Run the local dev server from this folder (serves with no-cache headers):

```powershell
python serve.py        # optional: python serve.py 8080
```

Then visit `http://localhost:8000`.

## Content Notes

Tuition, current availability, the street address, and a phone number are not published. Families
are directed to email Mayza for those details.
